# v1.4.0: Alerting System

## Overview

Add comprehensive alerting system for AI risk management. Completes the risk management loop: **Audit → Detect → Alert**, enabling timely response to security incidents.

## Features

### Alert Channels

- ✅ **Webhook Channel**: Custom HTTP endpoints with authentication
- ✅ **Email Channel**: SMTP email notifications with TLS support
- ✅ **Slack Channel**: Incoming Webhook with rich formatting

### Alert Management

- ✅ **Alert Rules**: Route different violations to different channels
- ✅ **Severity Levels**: low, medium, high, critical
- ✅ **Rate Limiting**: Token bucket algorithm (default: 10 alerts/minute)
- ✅ **Cooldown Mechanism**: Suppress duplicate alerts (default: 5 minutes)
- ✅ **Retry Logic**: Exponential backoff for transient failures

### Reliability

- ✅ **Alert Storage**: JSONL persistence for audit trail
- ✅ **Async Processing**: Queue-based worker for non-blocking alerts
- ✅ **File Rotation**: Automatic rotation at 100MB

### Security

- ✅ **PII Masking**: Never include raw PII in alerts (`138****5678`)
- ✅ **Bearer Token**: Authentication for webhook endpoints
- ✅ **TLS Encryption**: Secure transmission for all channels
