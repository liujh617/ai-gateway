# Release v1.2.0: PII Detection Feature

## Summary

Add PII (Personally Identifiable Information) detection capability to identify and alert on sensitive data exposure in AI interactions, supporting compliance requirements in regulated industries.

## Key Features

### PII Detection Types

- **Chinese Phone Number**: 11-digit mobile numbers (accuracy > 95%)
- **Chinese ID Card**: 18-digit resident ID cards (accuracy > 98%)
- **Chinese Bank Card**: 16-19 digit bank card numbers (accuracy > 90%)

### Action Modes

- **alert**: Log warning and add `pii_detected` field to audit event (default)
- **reject**: Block requests containing PII before sending to AI provider
- **allow**: Log informationally, continue processing

### Configuration

```json
{
  "pii_detection": {
    "enabled": true,
    "action": "alert",
    "log_pii": false,
    "redact_pii": true,
    "detect_phone_number": true,
    "detect_id_card": true,
    "detect_bank_card_number": true
  }
}
```

### Environment Variables

- `GATEWAY_PII_DETECTION_ENABLED`: Enable/disable detection
- `GATEWAY_PII_DETECTION_ACTION`: Set action mode

## Performance

- Detection latency: **< 5ms P99**
- No significant throughput impact
- Runs asynchronously after request completion (except for `action: reject`)

- `internal/audit/pii_detector.go`: Regex-based PII detector
