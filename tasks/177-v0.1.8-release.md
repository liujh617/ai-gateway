# Task 177 - v0.1.8 Release

## 背景

自 v0.1.7 以来的变更汇总发布。

## 新功能

- Audio API：transcriptions、translations、speech（Task 152）
- Batches API：create、list、retrieve、cancel
- Files API：upload、list、retrieve、delete、download（Task 176）
- Agent Audit：inspect 子命令、JSONL 轮转

## 质量改进

- 提供者测试覆盖率：61.8% → 63.6%（openai +24.2%, azureopenai +17.5%）
- 消除 ~500 行重复代码（fallback 泛型 helper + doJSONRequest）
- 数据安全：流式 store 失败审计、早期错误审计统一
- 未知字段策略统一、validJSONValue 去重
- UnmarshalJSON 错误包装、MarshalJSON 错误处理
